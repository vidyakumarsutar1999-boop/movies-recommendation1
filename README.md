# 🎬 Movie Recommendation System

A **Content-Based Movie Recommendation System** built using **Python, Machine Learning, NLP, Scikit-learn, and Streamlit**.

The system recommends movies similar to a movie selected by the user. It uses movie information such as **overview, genres, keywords, cast, and director** to calculate movie similarity.

---

## 📌 Project Overview

The Movie Recommendation System analyzes movie-related textual information and converts it into numerical vectors using **CountVectorizer**.

After vectorization, **Cosine Similarity** is used to calculate the similarity between movies.

The Streamlit application allows users to:

* 🎬 Select any movie from the dataset
* 🔎 Search/select a custom movie
* 🔢 Choose the number of recommendations
* 🎯 Get similar movie recommendations
* ⭐ View similarity scores
* 📊 Explore the movie dataset

---

# 🚀 Features

### 🎥 Custom Movie Selection

Users can select any available movie from the dataset.

### 🔢 Custom Recommendation Count

Users can choose how many recommendations they want.

Example:

```text
1 Movie
5 Movies
10 Movies
15 Movies
20 Movies
```
